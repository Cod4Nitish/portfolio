# Nitish Kumar Singh — Portfolio

**Live:** https://nitish-portfolio-bice-three.vercel.app/

AI Engineer focused on agentic systems: multi-agent workflows, RAG pipelines, and the APIs and web apps around them.

## What's inside

- **Guided explore mode:** tracks which sections a visitor has seen ("5/13 explored"), nudges them to the next one, and celebrates at 100%.
- **Live GitHub activity:** public repos, followers, stars, and recently pushed projects, straight from the GitHub API (cached, no token).
- **LinkedIn profile badge:** the official badge, loaded only when the Socials section is near the screen.
- **Visitor counter:** a small Vercel Function backed by Upstash Redis; stores only a salted hash, never raw IPs.
- **Two résumés from one data file:** an ATS version and a designed version, generated by `scripts/build-resume.mjs`.
- **Built for every device:** off-screen animations pause, and low-end phones get a lighter "lite" mode automatically.

## Stack

Plain HTML, CSS, and JavaScript (no framework, no build step), Vercel Functions (`api/`), and a Python + ReportLab résumé generator.

## Run locally

```sh
python -m http.server 4173
```

Then open http://localhost:4173/. (The visitor counter needs Vercel + Upstash, so it stays hidden locally.)

Everything editable lives in `content/portfolio-data.js`. See `PORTFOLIO-UPDATE-GUIDE.md`.
